# Summers Infinite Cleaning website

The finished website for Summers Infinite Cleaning (www.summersinfinitecleaning.com), built and maintained by To The Max Media.

- `site/` holds the complete, ready-to-serve website: every page, image, the sitemap and robots.txt. Netlify publishes this folder as it is; there is no build step (see `netlify.toml`).
- Every page is plain HTML with its text in normal headings and paragraphs, so search engines read it directly. Each page also has a plain-text copy (`index.md`) and the site has an `llms.txt` index for AI search tools.
- Updates are made by To The Max Media and pushed here; Netlify then publishes them automatically. Please don't edit these files by hand: the next update would overwrite the change.
